# Running a gateway

If you would like to run your own gateway, it is simple to do so.

We also have a repository to help you deploy your own gateway to a Hetzner cloud server in a matter of minutes. See [Deploy your own](/gateways/deploy-your-own) for more details.

To run a gateway:

## Checkout

Checkout the [repository](https://github.com/unruggable-labs/unruggable-gateways/tree/main).

```bash 
git clone git@github.com:unruggable-labs/unruggable-gateways.git
```

## Setup

Install [Foundry](https://getfoundry.sh/forge/reference/install/), and run the following setup commands

```bash
forge install
bun i
```

## Configuration

Copy the `.env.example` template to `.env` and define the appropriate environment variables.

```bash
ALCHEMY_KEY
INFURA_KEY
DRPC_KEY
```

## Run it

```bash
bun run serve <chain-identifier> [port]
```
